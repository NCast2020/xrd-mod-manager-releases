# Xrd Mod Manager

Mod manager for **Guilty Gear Xrd -REVELATOR- (REV 2)**: install and remove mods with buttons, no `.bat` files.

**[⬇ Download the latest version](https://github.com/NCast2020/xrd-mod-manager-releases/releases/latest)**: get `Xrd.Mod.Manager.zip`, unpack it anywhere and run `XrdModManager.exe`.

- Finds the game in Steam automatically.
- Drag a mod archive (.zip / .7z / .rar) or folder into the window, pick it, click **Install**.
- **Remove from game** brings the original files back.
- Warns about mods that conflict; overlay mods (d3d9.dll) work together.
- Updates itself: when a new version is out, a green **Update** button appears.
- English and Russian interface.

Requires Windows 10 or 11 (uses the built-in .NET Framework 4.8).

# Xrd Mod Manager (по-русски)

Менеджер модов для **Guilty Gear Xrd -REVELATOR- (REV 2)**: моды ставятся и удаляются кнопками, без батников.

**[⬇ Скачать последнюю версию](https://github.com/NCast2020/xrd-mod-manager-releases/releases/latest)** — скачай `Xrd.Mod.Manager.zip`, распакуй куда угодно и запусти `XrdModManager.exe`.

- Сам находит игру в Steam.
- Перетащи архив (.zip / .7z / .rar) или папку с модом в окно, выбери мод и нажми **Установить**.
- **Удалить из игры** возвращает оригинальные файлы.
- Предупреждает о конфликтующих модах; оверлеи (d3d9.dll) работают вместе.
- Обновляется сам: когда выйдет новая версия, появится зелёная кнопка **Обновить**.
- Язык переключается в правом верхнем углу (English / Русский).

Нужна Windows 10 или 11.
